# About Me

I'm a Principal Software Engineer focused on **software architecture, full-stack development, IoT, and distributed systems**. I build end-to-end solutions across web, desktop, mobile, backend, and connected devices, taking ownership from system design to deployment.

## Current Role & Key Contributions

At my current organization, I have been responsible for designing and developing a wide range of software products, automation solutions, and engineering infrastructure.

### Software Architecture & Engineering

- **KNX Remote Programming Platform:** Designed the architecture and developed its backend, database, web, and desktop components.
- **Dealer Portal & Internal CRM:** Led the architecture and end-to-end development of an integrated business platform.
- **KNX Device Factory Tool:** Designed and developed a desktop engineering application and its backend services.
- **Smart Home Communication Infrastructure:** Built server-side applications from scratch to connect and coordinate smart home devices.
- **Audio Streamer Device Integration:** Integrated an embedded audio streaming system with a touch-panel platform, resolving undocumented behaviors and compatibility challenges through system analysis and reverse engineering.

### Infrastructure & DevOps

- Built CI/CD pipelines connecting source code repositories to cloud infrastructure.
- Containerized Node.js applications using Docker.
- Managed cloud infrastructure, DNS, firewall policies, security configurations, and application traffic.
- Deployed and administered SIP-based communication infrastructure.

### Technical Leadership & Process Improvement

Earlier in my current organization, I also led the web development team, overseeing development planning, task allocation, daily stand-ups, progress tracking, and delivery coordination.

Applied Agile practices and improved engineering workflows through structured task management, centralized documentation, knowledge sharing, and cross-functional communication.

## Previous Experience

- Elevator control systems
- Smart home automation and temperature monitoring solutions
- SIP-WebRTC video intercom systems
